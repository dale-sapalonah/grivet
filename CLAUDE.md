# Grivet — realistic military FPS set in Port Moresby (Godot 4.7, GDScript)

Engine changed from the original UE5 plan: the dev PC is a Dell OptiPlex 5050
(i7-7700, Intel HD 630, ~28 GB RAM). Godot 4 runs on it and its scenes are
text, so code *and* levels are editable here. See Docs/Handoff.md (written as
"Project Meridian"; the game is now Grivet, the folder keeps its old name).

## Rules
- Gameplay code is GDScript, statically typed. Scenes (.tscn) and resources (.tres) stay text.
- All tuning lives in Resources (.tres under data/): weapons, enemies, AI, recoil. No magic numbers.
- Gameplay must run headless: every system gets tests runnable with --headless.
- Every system registers debug commands on the `Debug` autoload (god, give, spawn, ai.show).
- Original IP only: no Call of Duty names, assets, sounds or UI copies.
- Keep a licence record in Docs/AssetLicences.md for every imported asset pack.
- Performance target is this PC: 60 fps at 900p with 0.75 render scale. Profile before adding effects.

## Layout
core/ player/ weapons/ ballistics/ damage/ ai/ feedback/ ui/ mission/ — gameplay modules
data/ — tuning Resources   levels/ — scenes   assets/ — imported art/audio (LFS)   tests/ — test_*.gd

## Commands (run from the project root)
- Godot: `D:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe` (call it $GODOT)
- Import/check scripts: `$GODOT --headless --path . --import`
- Tests: `$GODOT --headless --path . -s res://tests/framework/run.gd` (exit code 0 = pass)
- Smoke-run main scene (the title menu): `$GODOT --headless --path . --quit-after 120`
- Movement traversal probe (drives the player through the greybox): `$GODOT --headless --path . res://tests/probes/movement_course.tscn` (prints PASS/FAIL per route; set PROBE_TRACE=1 for a per-frame trace)
- Gunplay probe (shoots the firing range: distances, drop, penetration, ricochet, recoil repeatability, reloads, pump): `$GODOT --headless --path . res://tests/probes/firing_range.tscn`
- GPU frame time + screenshot: `$GODOT --path . res://tests/probes/frame_capture.tscn -- [shot=<abs path>.png] [scene=res://...] [fire] [aim] [weapon=<id>] [hide_gun] [cmd=<console_command>]` (named options only, underscores in cmd= stand for spaces, e.g. `cmd=tp_-14_0_23 cmd=look_100_-4`; ignores real mouse/keyboard; defaults to the port level)
- Never pass empty-string arguments to Godot from PowerShell: it drops them and later arguments shift.
- Sounds are generated in code (feedback/procedural_audio.gd) from WeaponDefinition / SurfaceMaterial fields; Milestone 5 stayed procedural by choice (no recordings). Mechanism sounds fire at ViewModelTuning timing points so they match the animation.
- `Soundscape` autoload (feedback/soundscape.gd, tuning data/audio/audio_settings.tres, pure maths in feedback/sound_models.gd): builds every sound on a worker thread at start (a sound not built yet is skipped); gunshots are a close and a distant layer cross-faded by distance (SoundModels.shot_mix) and delayed by the speed of sound; enemy rounds within snap_radius of the camera snap; 8 rays + 1 up every 0.25 s measure the space and drive an AudioEffectReverb on SFX (near walls weigh more: alley ≈ 0.8 enclosure, open yard 0); footsteps by SurfaceMaterial.footstep_*; hit/kill/breath/ear-ring cues on the Cues bus (follows the SFX volume, skips reverb and deafness); a blast within deafen_radius enables a low-pass on SFX. Soldiers fire through Soundscape.gunshot, not their own player. Debug: `sound.demo` (listening check), `sound.acoustics`, `sound.deafen`. Probe: `$GODOT --path . res://tests/probes/soundscape.tscn`.
- Impacts are physics-driven: each hit reports outcome (penetrated / stopped / ricochet / exit), measured thickness (or solid) and remaining energy; SurfaceMaterial.acoustic_type + mass_factor (density x thickness) pick the sound and debris. Light rounds ricochet at steeper angles.
- Impact sounds are built on a worker thread (ImpactEffects); never build audio on the main thread during play. Effect shaders are pre-compiled when a camera first exists.
- Combat probe (arena: spotting, cover, flank, grenade, stuck check, ragdoll, blast, respawn, AI budget): `$GODOT --headless --path . res://tests/probes/combat_arena.tscn` (add `-- level=res://levels/port/port_yard.tscn` to run it on the port)
- AI: `AI` autoload (ai/ai_director.gd) owns the target, cover map, flank slot, grenade cooldown, noise and near-miss suppression. Soldier = body + senses + carrying out SoldierBrain (pure, tested) decisions. Enemy types are data/ai/*.tres (EnemyProfile); world tuning data/ai/ai_settings.tres.
- Levels with AI need a NavigationRegion3D named Navigation over CSG (`use_collision`); bake at runtime after CSG has built (2 frames), wait for the map iteration to change, then `AI.build_cover`. See levels/greybox/arena.gd. Navmesh cells are 0.125 m (project setting); doorways ≥ 1.6 m.
- The baked navmesh floats ~0.5 m above the floor: compare path points on the ground plane (CoverScoring.flat_distance), never in 3D.
- tools/gen_arena.py regenerates levels/greybox/arena.tscn; tools/gen_port.py regenerates levels/port/port_yard.tscn (the main scene: the arena's layout dressed as a container terminal at dusk). Colliders live in the generated scene; visual-only dressing (lamps, crane, ship, PMV buses, markings) is built by levels/port/port_yard.gd.
- Art is procedural (no downloaded assets): MeshBaker merges primitives into one vertex-coloured mesh per part/prop; surfaces are shaders over levels/port/materials/noise.tres (texture reads, not math noise: cheaper on the HD 630). Shipping lines and goods in markings are made up; PNG flavour comes from Tok Pisin, place names and street life (PMVs, PMV stop, buai market, palms), never real brands.
- Blender bodies: `"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup -P tools/blender/build_soldier.py -- assets/models/soldier_military.glb [--outfit civilian]` (soldier_civilian.glb: T-shirt=cloth, shorts=gear, hair=gear_dark, sandals=boots/sole) builds one mesh per Mannequin part in its part frame (metaball flesh, bevelled gear), vertex colours = material CLASS codes per face (0/1 channels; per-vertex codes blended into white seams). EnemyProfile.body_model is set on rifleman, rusher (military) and machete (civilian): Mannequin paints the classes from the profile (cached per palette) instead of building the parts; pivots, hit shapes, ragdolls and poses are unchanged; add-ons (bilum, strap, headband, machete) bake as separate meshes on the part (_bake_extras). RADIUS_GAIN 1.5 calibrates metaball size. Class edges: per-face colour on decimated faces zigzags, so hems (sleeves, shorts, boot tops) are cut straight with organic(..., hems=) and knee pads are hard pieces. Keep waists straight into the belt and give limbs calf/forearm bulges: thinner read as skeletons in game. Look check: `$GODOT --path . res://tests/probes/body_compare.tscn -- out=<dir>`.
- Flashbang (X, data/grenades/flash.tres, GrenadeDefinition.flash): no damage; Grenade._flash blinds everyone with a clear line from the bang to their eyes for ThrowMath.blind_seconds (distance, facing; tested). Soldier.flash: no sight, no fire, cowers (Soldier._blinded skips perceive/think). Player.flash: HUD whiteout; Soundscape.blast deafens. Probe: `$GODOT --headless --path . res://tests/probes/flashbang.tscn` (pin the soldier during the fuse: left alone it walks past the grenade).
- Knife (F, data/weapons/knife.tres, WeaponHolder.strike / `knife` command): MeleeMath (tested) picks the closest enemy in front; unaware, blinded or from the rear arc = silent takedown (Soldier.take_down, on_plate false: plates absorbed INF torso hits), else a cut. The takedown is committed at the key press (the victim turns during the windup). HUD shows "F  TAKEDOWN" when one is open. Probe: `$GODOT --headless --path . res://tests/probes/knife.tscn`. Synthetic Input.action_press misses is_action_just_pressed in probes: call the method.
- Squadmate (ai/squadmate.gd + .tscn, look/aim data/ai/squadmate.tres "Kori", a police officer, tuning AiSettings squad_*): campaign maps add one per level (campaign_level._ensure_squadmate) and regroup it by the player each stage. Follows off the player's right shoulder (navmesh), engages the closest visible enemy (AimModel, Ballistics, crouched), never fires with the player within squad_friendly_fire_clearance of the line, makes noise so enemies turn on it; not in AI.soldiers and not hunted (AI.target() is the player). Shot down = down for squad_downed_seconds, then up. HUD marks it (green chevron + name, red DOWN n). Debug `squad`, `squad.regroup`, `squad.down`, `squad.off`; the combat probe sets squad_enabled false (its shots made the enemy checks flaky). Probe: `$GODOT --headless --path . res://tests/probes/squadmate.tscn` (let a spawned soldier pose a few frames before AI.frozen, or its hit zones sit at its feet).
- The player's side is police (2026-10-30, user's pick): Kori uses soldier_police.glb (`--outfit police`: light-blue shirt = cloth/uniform_color, navy trousers = gear/shorts_color, beret, belt, epaulettes, patch = gear_dark/gear_color, badge and buckle = gloves/badge_color; EnemyProfile.Outfit.POLICE); the first-person sleeves are plain blue and the "gloves" skin (view_model_tuning.tres). Look and colours only: no real RPNGC crest or badge (original IP).
- Enemy shouts (Tok Pisin): AI.shout(soldier, situation[, urgent]) picks a ShoutLine from data/ai/shouts.tres (AiSettings.shouts: ShoutBook with gaps, threat range/chance per second, pitch range): spot (first alert), threat/melee (player in view within threat_range), grenade, blind (urgent: ignores the gaps). Voice from the head (pitched per soldier), words over it (Label3D) and as a HUD subtitle. Voices are placeholders from Windows TTS (tools/gen_voices.ps1, phonetic spelling); a recording saved as assets/audio/voice/<id>.wav replaces a line. AI.shout_log for probes: `$GODOT --headless --path . res://tests/probes/shouts.tscn`.
- First-person arms: weapons/view_arms.gd builds gloved hands around a grip radius and stretches forearms to elbow points (WeaponDefinition.*_elbow_offset); each view style in weapon_view_model.gd sets the hand holds (_right_hold, _left_hold, pump/magazine/loading-port holds). Colours live in view_model_tuning.tres.
- Game flow: ui/main_menu.tscn (title, the main scene) -> levels/port/port_yard.tscn. GameMenu (ui/game_menu.gd) is the title screen and, in every HUD, the Esc pause menu (pauses the tree). Settings autoload (core/settings.gd) saves to user://settings.cfg and applies live (volumes, Music bus, sensitivity, invert Y, FOV, render scale, shadows, fullscreen, FPS); `Settings.requested_stage` carries the menu's stage pick.
- Campaign: data/levels/campaign.tres (Campaign of CampaignStage: title, Tok Pisin subtitle, marker level, player start, difficulty multipliers applied per soldier by AI.spawn). Spawn markers carry metadata `level`; the plain arena spawns level 1 only. Clearing a stage shouts KLIN CHOL! / WARAA! (HUD.announce), then the next stage moves, heals and re-arms the player. `stage <n>` jumps. Probe: `$GODOT --headless --path . res://tests/probes/campaign.tscn`.
- Enemies: rifleman, rusher, machete (EnemyProfile.Role.MELEE, Outfit.CIVILIAN: T-shirt, shorts, sandals, bilum; WeaponDefinition.melee_* drives the strike). Bodies are MeshBaker lathes (smooth tapered limbs, sculpted heads); soldier_body.gdshader: COLOR.a 1 camo cloth, 0.5 plain cloth, 0 gear/skin.
- Town strip east of the yard (gate in the east wall): road, Kamfot taxi rank (levels/port/kamfot_taxi.gd, an original lookalike of the city's blue taxis), stores ("store" group, signs from metadata), rugby league field, buai market; buai bundles (BuaiPickup) heal and are re-laid each stage.
- Look: crime-sandbox box-art inspired, original (no Rockstar logo, font or wording). GrivetStyle (ui/grivet_style.gd) holds the fonts (Impact-style heavy, brush script) and colours; menus and HUD use it. Title art = CharacterPanel (ui/character_panel.gd): live 3D poses in their own worlds, rendered ~12 frames then frozen, through ui/comic_panel.gdshader (posterise, ink edges, halftone).
- Spawning: the port level is in group "spawn_picker"; Player.respawn() asks it for a spot (stage start if no enemy within safe_distance or with sight of it, else the safest of safe_spots), gives spawn protection (Health.protect) and AI.forget_target().
- Audio buses: Master, Music (MusicPlayer), SFX (every other sound player: Settings routes players left on Master to SFX as they are created; carries the Soundscape reverb and deafness low-pass), Cues (the player's feedback cues). Settings has volume and on/off for Music and for SFX + Cues together.
- MusicPlayer autoload (feedback/music_player.gd) builds the music on a worker thread (skipped headless) and plays it on the Music bus: MusicPlayer.play_set("menu"/"game"), the night ambience under the game set. The string-band loop is still in music.gd but out of rotation.
- Directional shadow map is 2048 (project setting). 4096 cost ~6 ms on the HD 630 (fill rate, worst with a low sun facing tall walls). No full-screen glow: lamps use additive halo billboards (halo.gdshader); glow cost ~2.7 ms.
- Ragdolls use Generic6DOFJoint3D with anatomical per-axis limits, built in the neutral pose then moved to the death pose (ai/ragdoll.gd). The joint's angle sign is opposite to Mannequin's pivot rotations (measured). HingeJoint3D/ConeTwist were tried and didn't behave predictably.
- Jointed ragdolls jitter and never sleep: a corpse freezes (FREEZE_MODE_STATIC) once settled or after AiSettings.corpse_freeze_after, and a blast wakes it (Ragdoll.wake). Ten unfrozen corpses at 120 physics ticks/s lagged the game. Soak probe (windowed, all stages, frame time/nodes/bodies every 10 s, corpse check): `$GODOT --path . res://tests/probes/soak.tscn [-- seconds_per_stage=<n>]`.
- Pushes on loose bodies (death, blasts) are velocity changes scaled by mass, never fixed impulses (light limbs would fly off).
- Collision layers: core/physics_layers.gd. Bullets hit Hitbox zone shapes (layer 4), never movement capsules.
- GUARD layer (32): railings and fences stop walking bodies and are walls to the navmesh (bake mask 33) but not bullets, sight, cover probes or sound. PRODUCE layer (64): market produce spheres, in BULLETS only.
- Maps: GameMenu.MAPS lists [name, scene, campaign]; START GAME picks a map. Both maps extend levels/campaign_level.gd (campaign stages, spawn picker, buai, lamp LOD, shared dressing; each map adds `_dress_level()`).
- Gordons Market (levels/gordons/, tools/gen_gordons.py regenerates the scene; campaign data/levels/gordons_campaign.tres): real site from OpenStreetMap, after hours, no civilians. Two-storey hall (DECK 4.8 m) with stairs, south ramp, footbridge; `cover_floors` lists both floors; region_min_size drops table-top navmesh islands; deck occluders (occlusion culling on). MarketProduce (market_produce.gd): produce per stall table via MultiMesh (near detail <12 m, lumps to 35 m), one sphere per heap on PRODUCE; shot or blasted it bursts; reset each stage. Probe: `$GODOT --headless --path . res://tests/probes/produce.tscn`.
- Cover map: probes once per floor (arena.cover_floors), only same-floor cover is requested (cover_max_climb), a direction is cover only if blocked across a body's width (cover_body_half_width), and points are bucketed in a 4 m grid (reserve/release by owner). Combat probe options: `-- level=... stage=<n> player=x,y,z`.
- Music (feedback/music.gd): in game covert_ops and tension alternate (dark military style, the user's pick), the menu keeps the island groove. Build tracks from sounds rendered once and stamped (_hit/_stamp) and tiled cores: per-sample synthesis of a minute in GDScript took minutes. Keep energy in 150-3000 Hz (sub bass alone is inaudible on small speakers). `tests/probes/music_timing.gd` times them and writes WAVs.
- Music level: the game set plays game_boost_db (13 dB, behind an AudioEffectHardLimiter on the Music bus) over the menu's level; at +8 the player heard the WAV on its own but not the game; at +3 it measured -25 dBFS under gunfire peaks near 0 and the player couldn't hear it. Measure real output with `$GODOT --path . res://tests/probes/music_level.tscn` (AudioEffectCapture on the Music and Master buses; AudioEffectRecord.get_recording() froze the engine here). At -20 the player still couldn't hear it (tension track especially): Music._glue now soft-saturates the dark tracks (tanh, GLUE_DRIVE) so drum peaks stop setting their level; they measure about -12 dBFS on the Music bus (`-- track=tension` measures the other one).
- Stragglers: with straggler_count soldiers or fewer left and no contact (AI.note_contact: a sighting, any hit, a squad spawning) for straggler_reveal_seconds, AI.stragglers_revealed() is true: the HUD marks them (through walls, edge arrows) and they hunt the player. The HUD always shows ENEMIES LEFT. `ai.stragglers` forces it. Probe: `$GODOT --headless --path . res://tests/probes/stragglers.tscn`.
- Sacks (levels/gordons/sack_mesh.gd): rounded superquadrics, instanced per pile (rounded sacks within sack_detail_distance, a block pile beyond), no shadows: thousands of instanced sacks drawn twice cost 3-6 ms.
- Frame-rate numbers drift with whatever else the PC is doing (Chrome on the shared iGPU). Compare against `scene=res://levels/boot/boot.tscn` measured in the same session before calling something a regression.
- Lights you toggle (muzzle flash): set `visible`, never just `light_energy = 0` — a dark light still costs every nearby pixel.
- The test runner fails any test that raises an engine or script error, not just failed asserts.
- Judge probes by their exit code, not just their PASS line: an engine crash at exit (exit 139) happens after the report prints.
- Every WorkerThreadPool task must be waited on (wait_for_task_completion, e.g. in _exit_tree) or the engine segfaults at exit; worker functions stay static and hand results to the main thread with call_deferred.
- Level-cycle crash probe (windowed: fights, frees the level mid-fight like `map`, quits): `$GODOT --path . res://tests/probes/level_cycle.tscn` (exit 0 and no SCRIPT ERROR lines = pass).
- Non-finite state (NaN/INF positions, velocities, move targets) floods the log with engine warnings that carry no script backtrace and stalls the game. Soldiers (_sane), the player, grenades and ragdolls detect it, push_error a one-time report with context, and recover. Respawn probe (windowed for 3D audio): `$GODOT --path . res://tests/probes/respawn_stress.tscn`.
- Every spring (recoil, camera kick, landing dip, soldier flinch) steps through Spring.step (core/spring.gd: fixed 1/120 s sub-steps, hitches capped); never hand-roll `v += (-k*x - c*v) * delta`. One Euler step per frame went unstable at low fps: it flung the first-person gun off screen, and far soldiers (posed every other frame) bent to 1e21 rad then NaN after a hit. Godot caps the frame delta at max_physics_steps (8) / 120 ≈ 0.067 s, so code that accumulates delta (pose LOD) sees larger steps than any one frame. View-model fire probe (windowed, forced slow frames): `$GODOT --path . res://tests/probes/view_model_fire.tscn`.
- Soldier._sane also checks rotation, aim pitch and the posed body (spine, muzzle), not just position; Ballistics.fire and CasingEjector.eject refuse non-finite input (one report each), and casings that go non-finite are recycled. A NaN casing never lands, so it used to warn every tick for ever (an 800 MB log).
- Menu-to-game probe (windowed: boots the title menu, presses Start, plays with mouse look and fire, scans every Node3D for non-finite transforms): `$GODOT --path . res://tests/probes/menu_to_game.tscn`.
- A freed object compares equal to null in Godot 4: test references that may outlive their target with `is_instance_valid(x)` alone, never `x != null and not is_instance_valid(x)`.
- AI alerts go through Soldier._alert() (awareness 1 + the alerted flag): setting awareness alone is undone by the next perception decay.
- Weapons are data: data/weapons/<id>.tres (WeaponDefinition). Surfaces: data/ballistics/surfaces/*.tres, mapped by id in ballistics_settings.tres; tag colliders with metadata `surface = "<id>"`.
- `Ballistics` autoload simulates all bullets; anything with `apply_damage(hit: Dictionary)` takes damage.
- Probes run as scenes, not `-s`: scripts that reference autoloads (Debug) don't compile under `-s`.
- Scene files store Transform3D row by row: `Transform3D(xx, yx, zx, xy, yy, zy, xz, yz, zz, ox, oy, oz)` in basis-column terms.
- Editor: `D:\Tools\Godot\Godot_v4.7.2-stable_win64.exe --path . -e`
