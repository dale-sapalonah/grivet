# Grivet beta (Android)

A first-person shooter set in Port Moresby, Papua New Guinea. This is an early test
build: expect rough edges, and tell us everything.

## Install (Android 7 or newer)

1. On your phone, open **[Grivet-0.6.1.apk](https://github.com/dale-sapalonah/grivet/raw/ccr-a6bed667-x7y962/beta/Grivet-0.6.1.apk)** (27 MB) and download it.
2. Open the downloaded file. If Android asks, allow installs from your browser or Files app, then tap **Install**.
3. If Play Protect warns about an unknown developer, tap **More details → Install anyway** (it's a test build, not from the Play Store).
4. Open **Grivet** (it has a blue robot icon for now). Play it in landscape.

## Controls

| | |
|---|---|
| Move | Put your left thumb down anywhere on the left half and drag. Push all the way forward to sprint. |
| Look | Drag anywhere on the right half. |
| FIRE | Hold to shoot. You can drag while holding it to aim at the same time. |
| AIM | Tap to aim down sights, tap again to stop. |
| RELOAD, JUMP, CROUCH | Tap. |
| NADE | Throw a grenade. |
| SWAP | Change weapon. |
| PLATE | Hold to put in an armour plate. |
| II (top right) | Pause. **Settings** in the pause menu has TOUCH LOOK SPEED and graphics. Back gesture pauses too. |

Start with **START GAME → PORT YARD**. Clear each stage of enemies to move on.
There's a second map, **GORDONS MARKET**.

## What we want to know

1. **Phone model**, and did it install and start? If it crashed, when (straight away, on the title screen, in a level)?
2. **Smoothness:** smooth, playable but choppy, or a slideshow? Does the phone get hot?
3. **Controls compared with the mobile shooters you play:** button size and spots, look speed (and what speed you set in Settings), the move stick, sprint, aiming. What feels missing or awkward? (For example: a left-side fire button, auto-fire, gyro aim, customisable layout.)
4. **Gunplay:** do the guns feel good? Recoil, hit feedback, reloads.
5. **Enemies:** too easy, too hard, unfair? Anything stuck or weird?
6. **What you'd change first.** Screenshots or screen recordings help a lot.
